# 首页底部导航重复点击设计

## 目标

用户已经位于首页时，再次点击首页底部导航项，首页主题列表自动滚动到顶部，并触发一次刷新。从其他底部页面点击首页时维持普通导航行为，不额外触发刷新。

## 方案

`MainShell` 维护无 replay 的首页重复点击请求通道。底部首页项被点击时：

- 当前路由不是首页：沿用 `navigateTopLevel(Home)`。
- 当前路由是首页：不重复导航，发送一次请求事件。

`HomeScreen` 收集请求事件并持有首页 `LazyListState`。每个事件立即发送一次现有 `HomeUiEvent.Refresh`，并在列表有内容时独立启动 `animateScrollToItem(0)`。通道消费后不重放，普通导航返回首页不会误刷新；快速重复点击也不会因滚动动画取消而漏掉刷新。

不新增全局事件总线，不把 Compose 列表状态提升到导航层，也不修改 Repository。

## 测试与验证

- 使用纯 Kotlin 决策函数测试：首页重复点击产生滚动刷新动作，其他路由点击首页产生导航动作。
- 运行导航局部测试、全量 JVM 单元测试和 Debug 构建。
- 模拟器或真机检查长列表滚动、刷新指示器和从其他底部页面返回首页的行为。
