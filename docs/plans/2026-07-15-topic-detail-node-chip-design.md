# 帖子详情节点 Chip 设计

## 目标

在帖子详情头部的“发帖人 · 发帖时间 · 点击数”元信息区域末尾展示节点 Chip。Chip 的标题、颜色、尺寸和节点名回退规则与帖子列表一致，点击后进入对应节点详情页。

## 方案

复用 `core.ui.topicNodeChip()` 生成展示标题和导航节点名，复用设计系统 `NodeChip` 渲染。详情页现有 `onNodeClick` 已连接根导航，无需修改导航层和数据层。

元信息文本与 Chip 放在同一个横向布局中：文本占用剩余空间并保持单行，Chip 固定放在末尾；节点名为空时不显示 Chip。这样既符合用户指定位置，也不会复制列表的节点映射规则。

## 测试与验证

- 新增纯 Kotlin 测试，证明详情页节点 Chip 使用节点标题展示、使用节点名导航，并在节点名为空时隐藏。
- 运行帖子详情局部测试、全部 JVM 单元测试和 Debug 构建。
- 人工检查 Chip 与元信息垂直对齐、长元信息截断，以及点击后进入正确节点页面。
